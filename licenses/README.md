# Third-party Licenses

Files marked `SPDX-License-Identifier: SHL-0.51` retain the Solderpad Hardware
License notice from PULP platform material. The authoritative license text is
available at <http://solderpad.org/licenses/SHL-0.51>. Attribution, affected
files, and origin are listed in the repository `NOTICE` file.

`pulp_common_cells_manifest.tsv` is the auditable source-to-component mapping
for imported design concepts. `make license-check` verifies that every
non-equivalent mapping retains a compatible SPDX notice and is listed in
`NOTICE`.

The repository-level `LICENSE` remains Mulan PSL v2. Per-file notices take
precedence for material received under a compatible upstream license.
